# Picture Postcards /LA

Source for picturepostcardsla.com, served by GitHub Pages.

- `index.html`: the whole site (splash, gallery, lightbox, postmarks).
- `img/`: web-sized postcards (`ppla-01.jpg` to `ppla-67.jpg`, plus `ppla-car.jpg`, `ppla-lake.jpg`, `ppla-splash.jpg`). Gallery order matches the @postcards.la Instagram feed.
- `CNAME`: the custom domain.
